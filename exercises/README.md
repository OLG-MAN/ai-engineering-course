# Exercises

Small per-lesson tasks from the "Hands-on exercise" column of [PLAN.md §4](../PLAN.md#4-the-course-lesson-by-lesson).
One folder per lesson: `exercises/<LNN>-<slug>/` (e.g. `exercises/L03-provider-agnostic-client/`).

If an exercise belongs in the capstone (OpsCopilot), build it there and link the PR from the lesson note instead.
